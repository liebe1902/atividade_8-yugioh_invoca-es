# Universo Yu-Gi-Oh!

## Sobre o projeto

O **Universo Yu-Gi-Oh!** é um site educativo desenvolvido com **HTML e
CSS** para apresentar informações sobre o universo do jogo de cartas
Yu-Gi-Oh!, com foco nas diferentes formas de Invocação de Monstros e em
seus aspectos básicos e estratégicos.

O projeto possui uma página inicial e cinco páginas temáticas. A
navegação entre elas é feita por um menu presente nas páginas,
permitindo que o visitante explore os conteúdos.

## Páginas do site

  -----------------------------------------------------------------------
  Arquivo                             Conteúdo
  ----------------------------------- -----------------------------------
  `pagina_inicial.html`               Apresenta o universo Yu-Gi-Oh!, um
                                      resumo da história da franquia,
                                      cartas famosas e as diferenças
                                      entre o jogo casual e o
                                      competitivo.

  `invocação_normal.html`             Explica a Invocação Normal, as
                                      regras gerais de Nível e a
                                      Invocação por Tributo, com o
                                      exemplo do Dragão Branco de Olhos
                                      Azuis.

  `invocação_fusão.html`              Apresenta a Invocação-Fusão, os
                                      Materiais de Fusão, a preparação
                                      necessária e algumas vantagens
                                      estratégicas dos Monstros de Fusão.

  `invocação_sincro.html`             Explica o uso de Reguladores e
                                      monstros não Reguladores, a soma
                                      dos Níveis e o planejamento das
                                      jogadas Sincro.

  `invocação_xyz.html`                Aborda a sobreposição de monstros
                                      de mesmo Nível, os Materiais Xyz e
                                      o uso desses materiais para ativar
                                      efeitos.

  `invocação_especial.html`           Reúne explicações sobre
                                      Invocação-Ritual, Invocação-Pêndulo
                                      e Invocação-Link, além de comentar
                                      a escolha da mecânica adequada para
                                      cada estratégia.
  -----------------------------------------------------------------------

## Tecnologias utilizadas

-   **HTML5:** estruturação das páginas, organização dos conteúdos e
    criação dos links de navegação.
-   **CSS3:** estilização visual das páginas por meio de folhas de
    estilo externas.

## Organização dos arquivos

Os documentos HTML fazem referência a folhas de estilo externas
localizadas na pasta `css/`. A estrutura esperada do projeto é:

``` text
universo-yu-gi-oh/
├── html/
│   ├── pagina_inicial.html
│   ├── invocação_normal.html
│   ├── invocação_fusão.html
│   ├── invocação_sincro.html
│   ├── invocação_xyz.html
│   └── invocação_especial.html
└── css/
    ├── pagina_inicial.css
    ├── invocação_normal.css
    ├── invocação_fusão.css
    ├── invocação_sincro.css
    ├── invocação_xyz.css
    └── invocação_especial.css
```

Os caminhos indicados nos arquivos HTML pressupõem que as páginas
estejam dentro da pasta `html/` e os arquivos CSS dentro da pasta
`css/`, ambas no mesmo nível.

## Objetivo

O objetivo do projeto é apresentar, de maneira organizada e acessível,
algumas das principais mecânicas de Invocação de Yu-Gi-Oh!, ajudando o
visitante a compreender seus requisitos básicos e suas aplicações
durante os duelos.
